# 伪洞察与重点宣布

这类句式不直接增加信息，而是告诉读者“现在请觉得这件事很重要”。AI 经常把它当作段首和转折工具。

## F01 真正系列

高风险形式：

- 真正值得关注的是……
- 真正重要的是……
- 真正有意思的是……
- 真正的问题在于……
- 真正决定胜负的是……
- 真正拉开差距的是……
- 真正值得警惕的是……
- 这才是真正值得关注的地方。

默认动作：`DELETE` 或 `DIRECT`

不要把“真正”换成“关键”“核心”“更重要”。直接进入内容。

## F02 值得注意系列

高风险形式：

- 值得注意的是……
- 更值得注意的是……
- 值得一提的是……
- 需要注意的是……
- 一个容易被忽略的细节是……
- 不容忽视的是……

默认动作：`DIRECT`

如果真是细节，直接写细节。如果需要说明为什么值得注意，用具体影响补充。

## F03 目标、答案、方向很明确

高风险形式：

- 目标很明确……
- 答案很明确……
- 方向已经很清楚……
- 信号已经非常明确……
- 结论其实很简单……

这类结构经常与冒号组合，形成“判断 + 冒号 + 解释”的 AI 句式。

默认动作：`DELETE`、`DIRECT`、`SPLIT`

原句：OpenAI 同时调整 API 定价和 Codex 配额，目标很明确：让开发者更多留在自己的平台里。

改写：OpenAI 最近同时调整了 API 定价和 Codex 配额。几项动作都在降低平台内开发的成本，它在继续提高开发者留在自家工具链里的意愿。

更自然的版本可以直接写事实，不强求补一句意图判断。

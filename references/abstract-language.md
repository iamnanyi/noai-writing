# 抽象词、AI 高频词和空洞落点

这些词不是绝对禁词，但它们很容易替代事实。每次出现都要检查是否有必要。

## 高风险重点词

真正、值得关注、值得注意、核心、关键、本质、底层逻辑、某种意义、显然、毫无疑问、不难发现、不容忽视、重新定义、重塑、赋能、范式、生态、边界、维度、路径、抓手、想象空间、深远影响、重要意义、关键一步、全新阶段、游戏规则、分水岭、转折点、里程碑、释放信号、折射、悄然发生、迎来、迈向。

## 处理规则

1. “真正、值得、核心、关键”如果只是宣布重点，删掉。
2. “本质、底层逻辑”必须能被具体因果替换，否则删掉。
3. “重塑、重新定义、范式”必须能说清楚旧状态、新状态和证据，否则改成具体变化。
4. “生态、维度、路径、抓手”优先换成具体对象、步骤、工具和渠道。
5. “显然、毫无疑问、不难发现”通常是在替证据背书。改成证据本身。
6. “很多人、越来越多人、行业普遍认为”如果没有数据或来源，不要凭空添加。

## 空洞落点

以下结尾如果没有新增信息，默认删除。

- 这给行业带来了新的思考。
- 它提供了新的视角。
- 它打开了更多可能性。
- 它的意义远不止于此。
- 其影响不容小觑。
- 这无疑具有重要意义。
- 未来充满无限可能。

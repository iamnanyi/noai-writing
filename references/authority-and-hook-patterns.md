# 伪权威、伪共识与反转钩子

这类句式经常用“事实、现实、很多人、你以为”制造可信度或冲突，但句子本身并没有提供来源。它们在社交媒体稿和 AI 评论里尤其常见。

## A01 一个事实是 / 一个现实是

高风险形式：

- 一个事实是……
- 一个不争的事实是……
- 事实已经很清楚了……
- 一个现实是……
- 一个残酷的现实是……
- 我们必须承认……
- 不得不承认……

默认动作：`DIRECT`、`SPECIFY`

处理原则：删掉“事实是”“现实是”这层背书，直接写事实。如果它并不是可验证事实，而只是作者判断，要明确写成判断，不要伪装成事实。

## A02 很多人 / 大多数人 / 很少有人

高风险形式：

- 很多人以为……
- 大多数人关注的是……
- 很少有人真正注意到……
- 很多人没有意识到……
- 行业普遍认为……

默认动作：`DELETE`、`SPECIFY`

处理原则：没有调查、数据、引述或明确样本，就不要凭空创造“多数人”。如果文章真正想表达的是“常见看法与事实有差异”，给出具体来源。

## A03 你以为 / 其实

高风险形式：

- 你以为 A，其实 B。
- 事情可能和你想的不一样。
- 别急着下结论。
- 答案可能出乎很多人的意料。
- 你可能没有意识到……

默认动作：`DIRECT`

处理原则：不要替读者预设错误认知。直接陈述 B，或者明确指出哪一种公开观点存在问题，并给证据。

## A04 科幻已经发生 / 我们正在见证

高风险形式：

- 听起来像科幻，但它已经发生了。
- 我们可能正在见证……
- 你正在见证……
- 历史可能正在我们眼前发生。

默认动作：`DELETE`、`GROUND`

处理原则：用具体事件本身建立冲击力，不要用旁白提醒读者“这很震撼”。
